# Contributing

Contributions are welcome through pull requests.

1. Create a branch from `main`.
2. Add tests for observable behavior changes.
3. Keep Oracle support general: extend grammar primitives and canonical rule
   IR instead of adding card-name branches.
4. Run the formatter, Clippy, tests and public-tree audit from the README.
5. Explain protocol or replay-schema compatibility effects in the PR.

Direct pushes to `main` are disabled. A maintainer review and passing required
checks are expected before merge.
