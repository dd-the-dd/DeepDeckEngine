La bonne fondation existe, mais le chemin critique contourne ses abstractions.

Le dépôt possède déjà une normalisation, une IR canonique et des familles de capacités. La dette vient surtout du retour au texte brut, des fallbacks successifs et de l'interprétation JSON répétée.

    Décision d'architecture

    Ne pas charger du code : compiler un plan de partie.

    Le besoin derrière le « subsection loader » est valide. La spécialisation doit porter sur les données et les index actifs, pas sur le chargement dynamique de modules Rust.

    Loader dynamique de modules

    Non recommandé. Le code Rust non exécuté coûte peu pendant la partie. Cela ajoute des frontières de modules dynamiques sans éviter les scans de l'état.

    CompiledGamePlan

    Recommandé. Au démarrage, analyser les cartes uniques et construire uniquement les tables nécessaires à cette partie.
