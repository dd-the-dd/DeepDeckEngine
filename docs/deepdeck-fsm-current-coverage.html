Mémoire transitoire
La machine peut revenir en arrière
Avant un enfant, le curseur capture un checkpoint. Un soft mismatch détruit les slots enfants et restaure la position. Après engagement d’une famille, une erreur remonte au lieu de cacher le problème dans le legacy.
1 · checkpoint
position + state + trace length
2 · tentative
Un AttemptFrame local reçoit source, amount, selector, costs ou binding.
3 · commit
Une valeur Rust typée remonte et la nouvelle position est conservée.
4 · rollback/failure
Avant engagement : rollback. Après engagement : diagnostic structuré.
Exemple : pour « you gain 3 life », DamageEffect peut reconnaître you, puis voir que le verbe n’est pas deals. Il rollback avant you; LifeEffect reçoit alors exactement le même flux intact.
