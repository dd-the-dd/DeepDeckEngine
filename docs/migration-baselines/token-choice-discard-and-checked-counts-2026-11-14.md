## Shared changes

Named-token specifications share one quantity/catalog/noun recognizer. An OR
list emits existing chooseOneEffect options containing ordinary createTokens;
the choice happens at resolution. A contextual lexical FSM recognizes exact
catalog names introducing reminder descriptions, with parenthesis and global
quote scope. It does not introduce Food- or Treasure-specific syntax.

Ordinary controller discard is one typed effect-sequence child. Existing player
discard/count/selection readers and runtime discard primitives are reused.
Draw/discard ordering is represented by ordinary sequence nodes, with real
same-face X binding. Mana children leave comma/and/then connectors for the
parent effect sequence instead of consuming them as mana-option punctuation.

Numeric validation checks all arithmetic AST children without allocating
temporary IR. Runtime discard and random-card-choice counts use a small checked
IR-tree adapter around the existing checked_integer_arithmetic kernel. Unary,
absolute-difference, min/max and conditional wrappers cannot hide saturated
children; only the selected conditional branch executes. Missing bindings,
overflow and division by zero raise errors. Valid negative counts retain the
existing zero normalization after successful evaluation.

One shared resolution preflight visitor owns rollback. Its shallow decision
facts now include discard, token choices and random card selection. Immediate
mana followups inspect the selected actual ability before costs, so a later
failure also restores tap/payment/mana. Discard remains correctly classified as
hand-to-graveyard movement, not library movement under cached CR605.1a.
