# Marvel Super Heroes migration baseline — 2026-11-09

This baseline measures the complete Scryfall `msh` set after the primitive-IR
architecture and executable-contract audit were introduced.

## Coverage

| Classification | Cards | Coverage |
|---|---:|---:|
| Complete set | 281 | 100% |
| Canonical parser result | 208 | 74.02% |
| Structurally primitive IR | 204 | 72.60% |
| Contract-executable primitive IR | 204 | 72.60% |
| Contract-rejected primitive IR | 0 | 0% |
| Canonical composite IR | 4 | 1.42% |
| Unsupported | 73 | 25.98% |

The 204 contract-executable cards and 77 gaps contain 281 distinct
`oracle_id` values, with no overlap, missing card, or collector-number
collision. Contract executability proves that the engine recognizes the full
IR shape; it does not replace card-specific runtime behavior tests.

Compared with the previously reported historical baseline of 122/281
executable canonical cards (43.42%), primitive executable coverage increased
by 82 cards and 29.18 percentage points, a 67.21% relative increase. The
historical run used the older, non-recursive audit and is retained as a trend,
not as a method-equivalent benchmark.

Both complete runs stayed below the 300-second target. The second run is not
a stable warm benchmark because concurrent parser migrations invalidated the
fingerprints. A true warm comparison must be recorded after the set is
finished and the source tree is stable.

## Reproduction

```powershell
.\scripts\audit-card-set.ps1 `
  -SetCode MSH `
  -TargetDirectory .tmp\targets\card-migration `
  -CacheDirectory .tmp\card-migration-cache `
  -BudgetSeconds 300
```

The runner must materialize `New-AuditInputs` as an array. This baseline also
regresses the single-set PowerShell scalar-unrolling bug fixed by wrapping the
call in `@(New-AuditInputs $queue)`.
